# Mandatory course-material onboarding

## Entry requirement

Before teaching, explaining a concept, hinting, grading, solving, or classifying techniques, obtain **at least one learner-provided textbook/theory file** and read the relevant section. A problem sheet, book title, unread link, checkpoint, or search result does not replace it. A study guide qualifies only if its actual contents provide the necessary definitions/theorems/methods; do not infer this from its name.

Source onboarding means receiving and reading sources. Coordinate it with progressive learner onboarding described in the skill: reuse known answers, ask a few high-impact questions about goals/constraints or explanations when needed, and keep optional questions deferrable. Do not require the learner to retell their study history. A learner profile does not waive the theory-file requirement.

Example when theory is missing:

> Please send the textbook or theory file you are studying, and the problem if available. I will read the relevant section, use it for Method 1, and explain it intuitively within that scope. If a verified internet approach is useful, I will show it separately as Method 2. I have kept your current study location and will resume there once the required material is accessible.

Do not request a problem already supplied. If theory lacks the topic, request the specific chapter/pages or additional file. If unreadable, identify the access/readability issue and request a usable copy; onboarding is not complete.

## Once files arrive

1. **Inventory roles:** theory/textbook, original problems, and solution guide. Record actual names, readability, and intended topic.
   Identify the actual mathematics subject and map each theory file to that subject; a file for one course does not automatically onboard another.
2. **Choose the primary theory source:** follow the learner's choice. Otherwise prefer identifiable course/instructor material and state the provisional choice. Clarify only meaningful conflicts in notation, method, or level.
3. **Read the relevant section:** definitions, theorem conditions, procedures, notation, permitted methods; locate through contents when helpful. Inspect scanned pages if tools support it; do not use unreadable content. Record real section/page locators, not fabricated citations.
4. **Confirm briefly:** source/section, applicable methods, missing scope, and the relevant learner-profile settings being applied. Begin if the current objective and sources are sufficient; optional profile fields may remain provisional. Do not add a ceremonial approval round.
5. **Record the source map:** confirm only topics sufficiently read, not the whole course from a few pages.

## Reuse and long sessions

- Read the corresponding theory before introducing a new technique; update the map beyond the previous scope. Initial onboarding is not permission to teach the rest from memory.
- Preserve the file's methods and conditions in Method 1. Adapt language, labeled original examples, and step size for ELI5, without silently replacing the theory with an advanced outside technique.
- If no applicable method is covered, identify the gap and request the missing theory. Internet research cannot satisfy the onboarding gate by itself.
- For source errors or contradictions, identify the location and verify the mathematics; do not propagate a false result to remain source-aligned. Separate corrections from outside alternatives and clarify affected assumptions.
- In a new chat, recheck actual access. Reuse sufficient files and the source map without starting onboarding from zero. A checkpoint claiming onboarding without accessible sources requires restoring the missing material.

## Internet alternative

Introduce Method 2 only after a valid Method 1 exists. Research when there is a concrete opportunity for faster work or clearer intuition, read a reliable source, and check its assumptions and calculations. Routine arithmetic does not need repeated browsing.

```text
Method 1 — Your course material
Source: [actual file and section/page]
[Intuition and hint/worked reasoning appropriate to the current mode]

Method 2 — Internet alternative
Source: [direct URL and section actually read]
Benefit: [fewer steps / clearer intuition / useful conditions]
Difference: [method, conditions, or additional prerequisites]
[Content within the current mode; no answer leak during guided practice]
Exam use: [whether it meets the specified method and any limitation]
```

Do not put Method 2 first, blend it into the course method, or attribute recalled tricks to the internet. Without an accessible verified source, continue Method 1 without inventing an empty alternative.
