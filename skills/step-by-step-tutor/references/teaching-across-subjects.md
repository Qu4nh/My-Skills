# Teaching across subjects

Choose the teaching approach from what the learner must do with the material. A definition, a calculation, an evidence-based argument, and a practical task call for different worked examples. Reuse the reasoning or example when the learner moves from understanding a concept to using it.

| Task | Show the learner | Check before giving feedback |
| --- | --- | --- |
| Calculate or prove | Which givens and conditions suggest the rule, why the decisive step is valid, and what to write | Recompute or substitute, check units and assumptions, or test the logical implication |
| Explain a mechanism | Which parts interact, what changes first, and what that change causes | Check the direction of each causal link and the conditions under which it holds |
| Interpret a text or historical source | Which words or observations support the claim, what the context contributes, and how to connect the evidence to the conclusion | Verify the cited detail and the reach of the inference |
| Practice a language | Where a word or construction fits in context, how meaning changes in a nearby example, and how the learner can produce it | Check meaning, grammar, register, and the learner's intended message |
| Apply a procedure or trace code | The input, the changing state at each decisive step, the expected output, and a way to verify it | Trace a concrete input and check a relevant edge case |

## Mechanism example

If asked why current decreases when resistance increases, hold the voltage steady in the example. Compare a 6 V supply across a 3 Ω resistor and a 6 Ω resistor. The same voltage drives a smaller current through the greater resistance. Use Ohm's law for the assumed ohmic resistors to obtain 2 A and 1 A. For practice, ask what changes if both resistance and voltage double. This checks the condition the learner must track.

## Evidence example

If asked whether a source establishes that a rule reduced lateness, use a small example with a dated school notice announcing the rule. The notice supports when the rule was announced and how the school described it. Attendance records before and after implementation would help test its effect. In an exam answer, have the learner cite the relevant detail, explain the inference, and identify the missing outcome evidence.

## Procedure example

If asked how a running sum works, walk through adding 2, then 4, then 1 to a total that starts at 0. Show the state sequence 0 → 2 → 6 → 7. Link each change to the same step, “add the current item to the previous total.” To check transfer, ask what initial value and output should be used for an empty list.

## Keep the useful parts when the lesson changes

When the learner says “teach the next section the same way,” preserve what helped them follow the previous lesson, such as one example carried through all the steps. Change the example and the proof or answer format to match the next section. If they pause to question a word, symbol, intermediate result, or cited detail, answer that point and then resume where they direct.
